# AI Readiness Assessment

Readiness is use-case-specific. An enterprise does not need to modernize everything before creating value, but the target workflow needs adequate foundations.

Score each priority use case from **1 (weak) to 5 (strong)**:

| Dimension | Questions |
|---|---|
| Business | outcome, owner, baseline and KPI clear? |
| Process | workflow understood; exceptions and approvals known? |
| Applications | systems of record and interfaces understood? |
| Data/knowledge | accessible, current, authorized, quality measurable? |
| Integration | APIs/events/tool boundaries adequate? |
| Identity/security | user, workload and agent permissions enforceable? |
| AI quality | evaluation set and acceptable failure thresholds defined? |
| Governance | accountability, risk tier, human authority defined? |
| Operations | logging, tracing, fallback and incident response possible? |
| Economics | expected unit cost/value and scale assumptions credible? |

A low score does not automatically stop the use case. It identifies what must be fixed or constrained in the transition architecture.
