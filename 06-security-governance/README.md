# Security & Governance — SGOE

AI transformation expands the trust boundary from users and applications to **models, retrieval pipelines, agents, tools, machine identities, external services and generated actions**.

## Security questions by CGOATKMM layer

| Layer | Representative concern |
|---|---|
| Channels | user/device authenticity, unsafe input, data leakage |
| Gateway | authentication, rate/policy enforcement, routing and filtering |
| Orchestration | policy bypass, unsafe state transitions, approval integrity |
| Agents | excessive autonomy, delegated privilege, confused-deputy behavior |
| Tools | least privilege, dangerous actions, transaction integrity |
| Knowledge | poisoning, unauthorized retrieval, provenance |
| Memory | sensitive persistence, cross-user leakage, retention |
| Models | misuse, supply chain, extraction, unsafe output, dependency risk |

**Governance** establishes owners, risk tiers, decision rights, human authority, evidence and lifecycle gates. **Observability** provides traceability. **Evaluation** tests whether controls and behavior work in representative conditions.

Use established frameworks such as NIST AI RMF/GenAI Profile and relevant security/application/AI standards as evidence sources; the repository method does not replace them.
