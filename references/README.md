# Evidence & Reference Register

The method is vendor-neutral. Sources support evidence and established concepts; they do not define the repository structure.

## Core sources (verified 2026-08-25)

### NIST
- **AI Risk Management Framework (AI RMF 1.0)** — voluntary, non-sector-specific, use-case-agnostic framework for managing AI risk and trustworthiness across design, development, deployment and use.  
  https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-ai-rmf-10
- **NIST AI 600-1 — Generative AI Profile** — cross-sectoral companion profile identifying generative-AI risks and suggested risk-management actions.  
  https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-generative-artificial-intelligence

### McKinsey
- **Rethinking enterprise architecture for the agentic era** — March 12, 2026. Discusses incremental integration versus broader transformation as enterprises modernize architecture for agentic AI.  
  https://www.mckinsey.com/capabilities/mckinsey-technology/our-insights/rethinking-enterprise-architecture-for-the-agentic-era

### PwC
- **The blueprint for an intelligent enterprise** — August 17, 2026. Emphasizes outcome-led transformation, connected technology foundations, workflow redesign and governance/accountability rather than isolated AI adoption.  
  https://www.pwc.com/us/en/intelligent-enterprise/ai-powered-enterprise-blueprint.html

## Source rules
- Prefer standards/regulators and primary technical sources.
- Use consulting/analyst research for industry observations, not as proof of technical correctness.
- Use official vendor documentation only when illustrating implementations.
- Record publication and last-verification dates for fast-changing claims.
- Do not reproduce proprietary diagrams or imply external endorsement of BCPADI → CGOATKMM → SGOE.
