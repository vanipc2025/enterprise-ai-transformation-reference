# Contribution Rules

## One concept, one home
Avoid repetition. Cross-link instead.

## Vendor-neutral first
Use: **requirement → capability → pattern → criteria → trade-offs → implementation examples**.

## Domain-neutral core
Domains demonstrate the common method; they do not create separate frameworks.

## Evidence
Distinguish original synthesis, standards/frameworks, vendor facts, industry statistics, illustrative assumptions and recommendations. Prefer primary/official sources. Date fast-moving technology claims.

## Diagrams
Create original diagrams; do not reproduce proprietary analyst/vendor graphics.

## Writing pattern
**Simple explanation → problem → choices → trade-offs → diagram → example → security/governance → economics → consultant checklist.**
